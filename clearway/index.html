How it works

How it works

Pick a resolver

The catalogue holds ad-blocking, family, security and unfiltered resolvers, each stating its transport, region and logging policy. Add your own DoH or DoT endpoint if you run one.

Approve it once

iOS does not let an app switch its own DNS on. Enable it yourself in Settings the first time — four taps. After that, changing resolvers in ClearWay takes effect immediately.

Test before you trust

ClearWay sends real DNS queries from your device, reports the round-trip time and counts how many known ad domains each resolver actually refuses to answer.

Features

Small app, no compromises

Measurement, not marketing

Every resolver can be measured from inside the app: real RFC 8484 queries, round-trip latency, and a per-domain count of what each one blocks. You see the numbers before you switch.

Encrypted by default

Apple's DNS Settings API accepts DNS over HTTPS and DNS over TLS and nothing else, so every resolver here is encrypted. The network you are on cannot read or rewrite your lookups.

Adult content filtering

The family resolvers filter adult sites for every app and browser on the device at once, which makes ClearWay a quick way to set up a child's iPhone or iPad.

Bring your own resolver

Add any DoH or DoT endpoint, or paste a NextDNS configuration ID to use your own blocklists. There is also a configuration profile export that needs no special entitlement.

Shortcuts and Siri

Turn protection on or off, or switch to a named resolver, from Shortcuts, Spotlight or the Action button.
